# Imagens do TCC

O infográfico de visão geral usado pelo README é
[`project_overview_2026-10-20.png`](project_overview_2026-10-20.png). Ele resume
a pergunta e o objetivo do manuscrito, a lista de 18 candidatos com 15 inclusões
provisórias, 14 triagens MMAT e 11 apreciações por categoria, além do protocolo ainda
não aplicado de avaliação da especificação. É uma síntese assistida, não um
resultado independente ou uma certificação científica.

O arquivo anterior `project_overview_current.png` foi preservado como artefato
histórico. Apesar do nome herdado, não representa o escopo reconciliado atual
e não deve ser reutilizado como visão vigente. Não se deve inferir eficácia
ou alteração de contagens a partir de uma imagem antiga.

As seis visualizações canônicas da revisão são copiadas de
`research/exports/visualizations/` pelo sincronizador de ativos derivados.
O infográfico é um resumo editorial separado: alterações no TCC e nos dados
exigem conferência textual e visual conforme o
[contrato de sincronização](../../../docs/tcc/DOCUMENTATION_SYNC.md).
